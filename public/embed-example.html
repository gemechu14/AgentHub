Welcome to My Website

This is an example of embedding the AgentHub chatbot widget. Look at the bottom-right corner — there's a chat icon!

How to Embed the Chatbot

Just add a single script tag before your closing </body> tag:

<!-- Add this before </body> --> <script src="http://localhost:3000/embed.js" data-token="YOUR_TOKEN_HERE" ></script>

That's it! The script automatically creates a floating circular chat button in the bottom-right corner. When clicked, it expands into a full chat popup.

How It Works

1. The embed script creates a small 60×60px circular button fixed to the bottom-right corner of your page.

2. When a user clicks the circle, the script expands the container to 400×600px and shows the chat interface.

3. When the user clicks the ✕ button, the chat closes back to the small circle.

4. No rectangular iframe borders — just a clean floating widget!

Optional: Custom Position

You can position the widget on the bottom-left instead:

<script src="http://localhost:3000/embed.js" data-token="YOUR_TOKEN_HERE" data-position="bottom-left" ></script>

Getting Your Token

1. Go to Admin Portal → Embed Configuration

2. Select an agent

3. Click "Generate Embed URL" on a credential

4. Copy the embed code snippet

5. Paste it into your website's HTML
